# Data Science Assignment 2 Cleaned Datasets

This repository contains cleaned datasets for FAST-NUCES Lahore Data Science Assignment 2. The same datasets will be used in Assignment 3.

## Netflix Dataset

* **File:** `23L_0726_A2_netflix_cleaned.csv`
* **Original source:** [Netflix Movies and TV Shows on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
* **Version:** v1.0
* **Date:** 10 October 2026

**Cleaning summary:** Column names and text values were standardized. Missing values were handled. Some incorrect rating entries were fixed. Date fields were prepared for analysis.

## Supermarket Sales Dataset

* **File:** `23L_0726_A2_supermarket_cleaned.csv`
* **Original source:** Dataset provided by the instructor
* **Version:** v1.0
* **Date:** 10 October 2026

**Cleaning summary:** Missing values and duplicate records were checked. Date and time fields were prepared for analysis. Possible sales outliers were kept because they were not confirmed errors.

## Versioning

Version v1.0 contains the cleaned datasets used in Assignment 2. These files will also be used in Assignment 3. Any future changes will be published as a new version.
